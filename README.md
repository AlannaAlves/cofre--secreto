
# 🔐 Cofre Secreto

## 📌 Sobre o projeto

O Cofre Secreto é um jogo desenvolvido com HTML, CSS e JavaScript, no qual o jogador precisa descobrir uma senha numérica de 3 dígitos para abrir um cofre.

## 🎯 Objetivo

Descobrir a senha correta de três números para conseguir abrir o cofre.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎮 Como jogar

1. Digite três números nos campos disponíveis.
2. Clique em "Tentar abrir" para verificar sua senha.
3. Se acertar os três números na posição correta, o cofre será aberto.
4. Se errar, o jogo mostrará quantos números você acertou.
5. Clique em "Ver dica" para receber pistas.
6. Clique em "Limpar" para apagar os números e começar novamente.

## 💡 Sistema de dicas

O jogo possui dicas que informam:

- Se cada número da senha é par ou ímpar.
- A soma dos três números da senha.

## 🔑 Senha atual

A senha configurada no projeto é `483`.

Para criar uma nova senha, basta alterar o vetor `senhaForte` no arquivo `index.js`.
